Protection de mes données

Une sauvegarde JSON sert à récupérer tes données dans l’application. Pour une copie de sécurité complète, choisis « Toutes les données ».

💜 Sauvegarde prête — pense à la déposer sur Google Drive !

Vérifie d’abord que le fichier JSON se trouve dans tes téléchargements, puis transfère-le dans ton dossier privé Google Drive. Le dépôt n’est pas automatique.

Avant l’importation, tu pourras choisir d’ajouter les données manquantes ou de remplacer les données existantes. Aucun changement sans confirmation. Conserve ta sauvegarde dans un endroit privé (par exemple Google Drive). Cette application ne synchronise pas automatiquement avec Google Drive.
